## Who you are

You are scaffolding **Lamppost** — an AI-powered interactive classroom platform forked from OpenMAIC (Tsinghua University's open-source multi-agent classroom). Lampost is not a chatbot. It is not a video platform. It is a complete virtual classroom where AI teachers lecture, draw on whiteboards, give quizzes, run interactive simulations — and students can raise their hand and interrupt at any moment to get a personalized answer.

The core architectural innovation: **ALL intelligence is pre-generated by Claude Opus 4.6.** The classroom runs on a pre-computed Q&A bank with 1,000-2,000+ entries per chapter. Real-time interaction is mostly embedding-based retrieval, NOT live LLM inference. A small fallback model handles only the 2-5% of questions that don't match the pre-built bank.

This is a real product. Not a demo. The code you scaffold will be iterated into production. The founder (Ripon) built a similar interactive-video-based edtech called Lamppost in 2019 using pure logic routing and pre-recorded video. This is the AI-native evolution of that same vision.

## Architecture Philosophy

**The Film Model**: You produce a film once (expensive). Then you show it to millions (free). But unlike a film, a student can pause and ask a question — and the system routes to the right pre-built answer instantly.

**Three-phase intelligence**:
1. **Opus generates everything** — lesson content, slides, narration scripts, whiteboard sequences, quizzes, AND a comprehensive Q&A bank covering every predictable student question. One-time cost per chapter.
2. **Embedding search handles 95%+ of real-time interactions** — student question → vector similarity → pre-built answer. Zero LLM cost.
3. **Fallback model handles the rest** — only truly novel questions that don't match the Q&A bank go to a live model (Sonnet, Gemma, or Haiku).

**The Flywheel**: Every unmatched question gets logged. Periodically, unmatched questions are batched and sent to Opus to generate new Q&A entries. The bank grows smarter with every student. After 6 months, match rate approaches 99%.

## Tech Stack Decisions (already made, do not change)

### Core Platform (forked from OpenMAIC)
- **Next.js 16** — App Router, server components, API routes
- **React 19** — UI rendering
- **TypeScript 5** — strict mode, no `any` types
- **pnpm** — package manager (OpenMAIC convention)
- **Tailwind CSS 4** — styling
- **shadcn/ui + Radix** — UI primitives (OpenMAIC convention)
- **Zustand** — client state management (OpenMAIC convention)
- **LangGraph 1.1** — multi-agent orchestration (OpenMAIC convention)

### AI / LLM Layer
- **Claude Opus 4.6** — lesson generation + Q&A bank generation (one-time, via Batch API)
  - API: `https://api.anthropic.com/v1/messages`
  - Model string: `claude-opus-4-6`
  - Pricing: $5/1M input, $25/1M output (50% off with Batch API)
- **Claude Sonnet 4.6** — fallback for unmatched classroom questions
  - Model string: `claude-sonnet-4-6`
  - Pricing: $3/1M input, $15/1M output
  - Use prompt caching aggressively (lesson context is always the same per chapter)
- **Google Gemini 3 Flash** — Bangla translation layer
  - For translating Opus-generated English content to Bangla
  - Also available as a cheaper classroom fallback for mass-market Bangla deployment
- **Gemma 3 12B via Ollama** — local self-hosted classroom model for offline/school deployments
  - OpenAI-compatible API at `http://localhost:11434/v1`
  - Zero marginal cost per interaction

### Embedding & RAG (the Q&A Bank)
- **PostgreSQL 16 + pgvector** — vector database for Q&A bank storage
  - Hosted via **Supabase** (managed Postgres, built-in pgvector, Row Level Security)
  - Why Supabase: auth, storage, realtime, edge functions, RLS — all in one
- **nomic-embed-text v1.5** via Ollama — local embedding model for generating vectors
  - 768-dimension embeddings
  - Runs locally, zero API cost
  - Alternative for cloud: **Voyage AI** embeddings (best-in-class for education/retrieval)
- **Similarity threshold**: cosine similarity > 0.85 = serve pre-built answer, < 0.85 = escalate to fallback LLM

### TTS (Text-to-Speech)
- **Google Cloud TTS** — Bangla voices (`bn-BD-Wavenet-A`, `bn-BD-Wavenet-B`)
- **OpenAI TTS** — English voices (`alloy`, `echo`, `nova`, `shimmer`)
- Pre-generated for all lesson narration (one-time cost, cached as MP3)
- Real-time TTS only for fallback LLM responses

### ASR (Speech Recognition)
- **Google Cloud Speech-to-Text** — Bangla (`bn-BD` locale)
- **OpenAI Whisper** — English (or `auto` language detection)
- Streaming via WebSocket for real-time classroom interaction

### Document Parsing
- **MinerU** — PDF parsing with OCR, table extraction, equation recognition
  - Self-hosted or API (`PDF_MINERU_BASE_URL` in env)
  - Critical for ingesting NCTB textbooks (Bangla script + mathematical notation)

### Deployment
- **Vercel** — primary deployment (Next.js native, edge functions, CDN)
- **Docker + Docker Compose** — self-hosted school/institutional deployment
- **Ollama** — local model serving for offline deployments
- **Supabase** — managed database, auth, storage

### Internationalization
- **Existing**: `en-US`, `zh-CN` (from OpenMAIC)
- **Adding**: `bn-BD` (Bangla)
- Font: **Noto Sans Bengali** (Google Fonts) + **Hind Siliguri** fallback
- Number system: configurable (Bengali numerals ০১২ or Western 012)

### Core tables

```sql
-- Curricula (SSC, HSC, O-level, A-level, University)
CREATE TABLE curricula (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,                    -- 'SSC', 'HSC', 'Cambridge O-Level', etc.
  board TEXT,                            -- 'NCTB', 'Cambridge CAIE', 'Pearson Edexcel'
  language TEXT NOT NULL DEFAULT 'en',   -- 'en', 'bn'
  country TEXT DEFAULT 'BD',
  metadata JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Subjects within a curriculum
CREATE TABLE subjects (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  curriculum_id UUID REFERENCES curricula(id),
  name TEXT NOT NULL,                    -- 'Physics', 'Mathematics', 'Chemistry'
  name_bn TEXT,                          -- 'পদার্থবিজ্ঞান', 'গণিত', 'রসায়ন'
  code TEXT,                             -- 'PHY', 'MATH', 'CHEM' or Cambridge code '9702'
  grade TEXT,                            -- 'Class 9', 'Class 10', 'AS', 'A2'
  total_chapters INTEGER,
  metadata JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Chapters within a subject
CREATE TABLE chapters (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  subject_id UUID REFERENCES subjects(id),
  chapter_number INTEGER NOT NULL,
  title TEXT NOT NULL,
  title_bn TEXT,
  description TEXT,
  source_pdf_path TEXT,                  -- path to NCTB/textbook PDF
  generation_status TEXT DEFAULT 'pending', -- pending, generating, complete, failed
  generation_model TEXT,                 -- 'claude-opus-4-6'
  generation_cost_usd DECIMAL(10,4),
  metadata JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Generated lessons (the "baked" classroom content)
CREATE TABLE lessons (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  chapter_id UUID REFERENCES chapters(id) UNIQUE,
  
  -- Stage 1: Outline
  outline JSONB NOT NULL,               -- structured lesson plan
  
  -- Stage 2: Scenes (slides, quizzes, simulations, whiteboard)
  scenes JSONB NOT NULL,                -- array of scene objects
  
  -- Agent personas for this lesson
  agents JSONB NOT NULL,                -- teacher, TA, classmates with personas
  
  -- Narration scripts (for TTS pre-generation)
  narration_scripts JSONB,              -- per-scene narration text
  
  -- Pre-generated audio paths
  audio_paths JSONB,                    -- per-scene MP3 file paths
  
  -- Bangla translation (if applicable)
  scenes_bn JSONB,                      -- translated scene content
  narration_scripts_bn JSONB,           -- Bangla narration text
  audio_paths_bn JSONB,                 -- Bangla audio file paths
  
  -- Export cache
  pptx_path TEXT,
  html_path TEXT,
  
  -- Generation metadata
  model_used TEXT NOT NULL,
  tokens_input INTEGER,
  tokens_output INTEGER,
  cost_usd DECIMAL(10,4),
  
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- ============================================================
-- THE Q&A BANK — This is the core innovation
-- ============================================================

CREATE TABLE qa_bank (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  chapter_id UUID REFERENCES chapters(id),
  
  -- The question (what a student might ask)
  question TEXT NOT NULL,
  question_bn TEXT,                      -- Bangla translation
  question_embedding vector(768),        -- nomic-embed-text vector
  
  -- The answer (Opus-generated, pedagogically perfect)
  answer TEXT NOT NULL,
  answer_bn TEXT,                        -- Bangla translation
  
  -- Context: when in the lesson does this question typically arise?
  scene_index INTEGER,                   -- which scene/slide triggers this
  topic_tags TEXT[],                      -- ['work', 'cosine', 'displacement']
  
  -- Classification
  difficulty TEXT DEFAULT 'medium',      -- easy, medium, hard
  question_type TEXT DEFAULT 'conceptual', -- conceptual, procedural, definitional, misconception, application
  
  -- Misconception handling
  common_wrong_answer TEXT,              -- what students typically answer wrong
  why_wrong TEXT,                        -- explanation of the misconception
  
  -- Whiteboard follow-up (if the answer needs a visual)
  has_whiteboard BOOLEAN DEFAULT false,
  whiteboard_instructions JSONB,         -- SVG drawing commands for whiteboard
  
  -- Source tracking
  source TEXT DEFAULT 'opus_generated',  -- opus_generated, student_derived, teacher_added
  opus_batch_id TEXT,                    -- which Opus batch generated this
  
  -- Behavioral data (updated by the flywheel)
  times_matched INTEGER DEFAULT 0,      -- how often this Q was matched to a student question
  times_helpful INTEGER DEFAULT 0,      -- student moved on (didn't ask follow-up)
  times_unhelpful INTEGER DEFAULT 0,    -- student asked follow-up (answer wasn't enough)
  avg_satisfaction DECIMAL(3,2),         -- computed from behavioral signals
  
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Index for vector similarity search
CREATE INDEX ON qa_bank USING ivfflat (question_embedding vector_cosine_ops) WITH (lists = 100);

-- Index for filtering by chapter
CREATE INDEX ON qa_bank (chapter_id);

-- Unmatched questions log (feeds the flywheel)
CREATE TABLE unmatched_questions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  chapter_id UUID REFERENCES chapters(id),
  student_id UUID,
  
  -- The question that didn't match
  question TEXT NOT NULL,
  question_embedding vector(768),
  
  -- What the fallback model answered
  fallback_answer TEXT,
  fallback_model TEXT,                   -- 'claude-sonnet-4-6', 'gemma-3-12b', etc.
  
  -- Did the student find it helpful?
  student_continued BOOLEAN,             -- true = moved on, false = asked follow-up
  follow_up_question TEXT,               -- if they asked a follow-up, what was it?
  
  -- Processing status
  status TEXT DEFAULT 'pending',         -- pending, sent_to_opus, added_to_bank, discarded
  opus_batch_id TEXT,
  new_qa_id UUID REFERENCES qa_bank(id),
  
  scene_index INTEGER,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Student interaction log (for behavioral analytics)
CREATE TABLE student_interactions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  student_id UUID,
  chapter_id UUID REFERENCES chapters(id),
  session_id UUID,
  
  -- What happened
  interaction_type TEXT NOT NULL,        -- 'question', 'quiz_answer', 'whiteboard_request', 'voice_input'
  
  -- The student's input
  student_input TEXT,
  student_input_embedding vector(768),
  
  -- How it was resolved
  resolution_type TEXT NOT NULL,         -- 'qa_bank_match', 'fallback_llm', 'pre_baked_playback'
  qa_bank_id UUID REFERENCES qa_bank(id),
  similarity_score DECIMAL(4,3),
  
  -- The response given
  response TEXT,
  response_model TEXT,                   -- 'qa_bank', 'claude-sonnet-4-6', 'gemma-3-12b'
  
  -- Cost tracking
  tokens_input INTEGER DEFAULT 0,
  tokens_output INTEGER DEFAULT 0,
  cost_usd DECIMAL(10,6) DEFAULT 0,
  
  -- Timing
  latency_ms INTEGER,
  
  created_at TIMESTAMPTZ DEFAULT now()
);

-- Students
CREATE TABLE students (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  auth_id UUID,                          -- Supabase auth user ID
  name TEXT,
  grade TEXT,                            -- 'Class 9', 'Class 10', 'O-Level', etc.
  medium TEXT DEFAULT 'bangla',          -- 'bangla', 'english'
  curriculum_id UUID REFERENCES curricula(id),
  
  -- Learning profile (built over time from interactions)
  weak_topics TEXT[],                    -- topics where they struggle
  strong_topics TEXT[],                  -- topics they've mastered
  interaction_count INTEGER DEFAULT 0,
  total_quiz_score DECIMAL(5,2),
  
  metadata JSONB DEFAULT '{}',
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);

-- Row Level Security
ALTER TABLE students ENABLE ROW LEVEL SECURITY;
ALTER TABLE student_interactions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Students can read own data" ON students
  FOR SELECT USING (auth_id = auth.uid());

CREATE POLICY "Students can read own interactions" ON student_interactions
  FOR SELECT USING (student_id IN (SELECT id FROM students WHERE auth_id = auth.uid()));
```

## Environment Variables

```bash
# .env.example

# ============================================================
# LLM PROVIDERS
# ============================================================

# Claude — Primary intelligence engine
ANTHROPIC_API_KEY=sk-ant-...

# Google Gemini — Translation layer + Bangla content
GOOGLE_API_KEY=...
```

## Classroom Interaction Flow — The Smart Router

```typescript
// lib/classroom-engine/interaction-handler.ts

import { searchQABank } from '../qa-bank/search';
import { routeToFallback } from './fallback-router';
import { wrapResponse } from './response-wrapper';
import { logInteraction } from './interaction-logger';

interface StudentInput {
  text: string;
  chapterId: string;
  studentId: string;
  sessionId: string;
  sceneIndex: number;
  language: 'en' | 'bn';
}

interface ClassroomResponse {
  text: string;
  text_bn?: string;
  source: 'qa_bank' | 'fallback_llm';
  agent: 'teacher' | 'ta' | 'classmate';
  hasWhiteboard: boolean;
  whiteboardInstructions?: any;
  confidence: number;
  costUsd: number;
}

export async function handleStudentInteraction(
  input: StudentInput
): Promise<ClassroomResponse> {
  
  // Step 1: Search Q&A bank via embedding similarity
  const qaResult = await searchQABank({
    question: input.text,
    chapterId: input.chapterId,
    sceneIndex: input.sceneIndex,
    topK: 3,
  });
  
  // Step 2: Check if best match exceeds threshold
  if (qaResult.bestMatch && qaResult.bestMatch.similarity >= QA_SIMILARITY_THRESHOLD) {
    // MATCH FOUND — serve from bank (zero LLM cost)
    const entry = qaResult.bestMatch.entry;
    
    const response: ClassroomResponse = {
      text: await wrapResponse(entry.answer, input, 'qa_bank'),
      text_bn: entry.answer_bn,
      source: 'qa_bank',
      agent: 'teacher',
      hasWhiteboard: entry.has_whiteboard,
      whiteboardInstructions: entry.whiteboard_instructions,
      confidence: qaResult.bestMatch.similarity,
      costUsd: 0, // Zero cost — served from database
    };
    
    // Log the interaction
    await logInteraction({
      ...input,
      resolutionType: 'qa_bank_match',
      qaBankId: entry.id,
      similarityScore: qaResult.bestMatch.similarity,
      response: response.text,
      responseModel: 'qa_bank',
      costUsd: 0,
    });
    
    // Increment match counter on the Q&A entry
    await incrementQAMatchCount(entry.id);
    
    return response;
  }
  
  // Step 3: No match — route to fallback LLM
  const fallbackResponse = await routeToFallback({
    question: input.text,
    chapterId: input.chapterId,
    sceneIndex: input.sceneIndex,
    language: input.language,
    // Include nearby Q&A entries as context so the fallback model 
    // has the "teacher's notes" even for novel questions
    relatedQAs: qaResult.topMatches.map(m => m.entry),
  });
  
  const response: ClassroomResponse = {
    text: fallbackResponse.text,
    source: 'fallback_llm',
    agent: 'teacher',
    hasWhiteboard: false,
    confidence: qaResult.bestMatch?.similarity || 0,
    costUsd: fallbackResponse.costUsd,
  };
  
  // Log interaction AND save to unmatched questions for flywheel
  await logInteraction({
    ...input,
    resolutionType: 'fallback_llm',
    similarityScore: qaResult.bestMatch?.similarity || 0,
    response: response.text,
    responseModel: fallbackResponse.model,
    costUsd: fallbackResponse.costUsd,
  });
  
  await saveUnmatchedQuestion({
    chapterId: input.chapterId,
    studentId: input.studentId,
    question: input.text,
    fallbackAnswer: fallbackResponse.text,
    fallbackModel: fallbackResponse.model,
    sceneIndex: input.sceneIndex,
  });
  
  return response;
}
```

## Critical Design Principles

1. **Never break OpenMAIC.** All additions are alongside existing code, not replacing it. The original OpenMAIC classroom playback, generation pipeline, and agent orchestration must continue to work. We are EXTENDING, not rewriting.

2. **The Q&A bank is the product.** The classroom playback is OpenMAIC. The LLM is Claude. The translation is Gemini. But the Q&A bank — the 2,000 pre-built answers per chapter, growing with every student interaction — that's what nobody can replicate. Treat it as the most important data in the system.

3. **Prompt caching everywhere.** Every API call that involves lesson context (which is 95%+ of calls) should use Anthropic's prompt caching. The lesson context for a chapter is identical for every student — cache it once, pay 90% less on every subsequent call.

4. **Batch API for generation.** Lesson generation and Q&A bank generation are NOT time-sensitive. Always use the Batch API (50% discount) for these operations. Only real-time classroom interactions use synchronous API calls.

5. **Log everything.** Every student interaction, every Q&A match, every fallback call, every unmatched question. The data is the flywheel. Without logging, you can't improve. The `student_interactions` table is the most valuable operational data you will ever collect.

6. **Bangla is a translation layer, not a generation language.** Claude generates in English (highest quality). Gemini translates to Bangla. TTS renders in Bangla. The student sees Bangla. But the intelligence is English-first. This ensures quality control and makes every lesson immediately available in both languages.

7. **Offline-first for schools.** A school in Rangpur with intermittent internet must be able to run Lampost on a local server. Pre-generated lessons + audio + Q&A bank + local Gemma via Ollama = fully functional classroom with zero internet dependency.

## The Soul of This Product

This is named after Ishwar Chandra Vidyasagar's vision — that every person deserves access to quality education regardless of where they were born. The founder built this same vision as "Lampost" in 2019 with pre-recorded video and logic routing. Now the technology exists to deliver it at scale.

A student in a village in Rangpur and a student in Gulshan and a student in London should all get the same quality of explanation when they ask "why is there a cosine in the work formula?" The Q&A bank doesn't know the difference. It just serves the best possible answer, instantly, for free.

Every engineering decision should serve that mission. When in doubt, optimize for the student's experience, not the developer's convenience.
